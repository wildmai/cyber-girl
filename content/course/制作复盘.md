# 视频制作与检查复盘

本次先制作无声预览，随后使用用户指定的豆包克隆音色完成有声版本。
用户暂缓配置密钥时继续完成文稿与画面，不擅自替换声音。

## 有效做法

1. 把一条“今天有点累，陪我聊聊”的语音请求作为贯穿例子，章节围绕输入、处理、播放和生命周期展开。
2. 保存真实截图的来源和摘要，把历史界面、命令示范、源码摘录、流程示意与性能实测分开说明。
3. 设置面板先保留完整安全边界，再做局部运镜，字幕和章名在运镜之后叠加。
4. 源码长行折行显示，保留原行号，使用系统字体支持的 ASCII 续行符，避免缺字和省略关键参数。
5. 将 LLM 启动参数、请求载荷和思考标签过滤分别切到对应源码，避免口播与泛泛的构造函数摘录脱节。
6. 使用独立审片检查自动门禁无法判断的模式错配、品牌和教学准确性。

## 本次发现的坑

| 现象 | 根因 | 修复与验证 |
|---|---|---|
| 人设设置正文裁边 | 将整张截图按固定焦点放大，未保留抽屉边界 | 设置类截图预留安全区域，复查运动峰值和回到全貌的帧 |
| MuseTalk 讲解出现云端状态 | 使用了不匹配的历史回复截图 | 换历史本地设置，注明非速度演示 |
| Mac 章节像是已在目标机器运行 | 使用云端设置作为本地性能画面 | 换内存估算与启动源码，明确待真机验证 |
| 字幕最后一行只剩孤字 | 固定宽度换行未处理极短尾行 | 把完整词组移到末行，再复查结尾 |
| 深色截图只有静态切换 | 主体动作和讲解节点不足 | 增加对应的源码与启动命令画面，采用定位与返回的镜头节奏，不修改门禁阈值 |
| 历史技术条露出被禁止品牌 | 只检查中段放大帧，漏看回到全貌及图解底图 | 在合成入口统一裁去技术条，检查所有引用该素材的镜头边界 |
| TTS 讲解沿用云端回复图 | 同一张回复图被用于不同工作阶段 | 换真实本地语音合成等待图，裁去旧服务技术条并标注历史界面 |
| 流动标签盖住验证层级 | 把请求动画无差别放到各类图解 | 验证图移除请求标签，保留层级文字 |
| GGUF 等英文专名被字幕拆开 | 只按字符宽度切分，未保护完整技术词 | 字幕按标点优先切分，英文名称作为整体换行 |
| 命令高亮与口播不一致 | 复用静态变体序号，未绑定真实口播时间 | 有声版取消静态逐行高亮，完整展示可执行命令 |
| 导出中断后 MP4 无法播放 | 输出直接覆盖目标文件，索引未写完 | 先封装到临时文件，核对音视频流与时长后原子替换 |

## 自动检查的边界

镜头表 lint 只能验证部分格式、时长和文字约束。
整片门禁对快速动作、空白和蓝紫底给出可重复的指标，不证明教学内容正确。
本工程的代表镜头 QA 使用实际 MP4 的栅格回放，能检查回放确定性和运动，不能追踪已烧录文字的外框。
最终画面由独立审片补足，长教程安排两位审片人。
无声预览通过检查也不意味着旁白已经对齐，更不代表目标 Mac 推理性能已经验证。
